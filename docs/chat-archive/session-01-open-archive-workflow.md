# Session 01 - Open Archive Workflow

Date: 2026-09-05

## Goal
Membuka chat/archive dari project lain di VS Code.

## Main Points
- Riwayat chat Copilot biasanya terkait workspace.
- Untuk melihat chat lama, buka folder/workspace project lama.
- Gunakan panel Chat -> History/Recent/Archived (jika tersedia di versi VS Code).
- Login harus menggunakan akun yang sama.

## Outcome
- Alur akses chat project lain berhasil dipahami dan bisa digunakan.

## Follow-up
- Untuk keamanan data, chat penting disarankan dibackup ke file Markdown di project.
